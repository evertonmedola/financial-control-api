## Phase Goal

**As a** developer and sole operator of this personal-finance API, **I want to** run it on AWS behind a load balancer with the database and secrets never exposed, **so that** I can use it for real, present it as a portfolio project, and practice the AWS Cloud Practitioner material on real infrastructure.

*(ROADMAP.md's Phase 8 `**Goal:**` line — "The API runs in AWS on managed, secure infrastructure — reachable from the internet only through a load balancer, with the database and secrets never exposed" — is a system-property sentence and names no actor, exactly like Phase 7's. The story above is a non-invented restructuring of that Goal line plus the three ROADMAP Success Criteria and PROJECT.md's stated purposes; no `/gsd mvp-phase 8` reformatting pass has run, mirroring 07-01-PLAN.md's handling of the identical situation.)*

## Acceptance Criteria

- [ ] The API is reachable over the internet only via the ALB; ECS tasks and RDS sit in private subnets with no public accessibility.
- [ ] Database credentials and the JWT secret are injected at container runtime from Secrets Manager — never present in the image, environment files, or CI logs.
- [ ] The ALB only routes traffic to ECS tasks that pass the `/health` check; an unhealthy task is automatically removed from rotation.

(This plan lays the free, non-billable groundwork for those criteria: AWS access, remote state, the JWT secret, and the Terraform root-module skeleton. Plans 08-02 to 08-04 deliver and prove them.)
