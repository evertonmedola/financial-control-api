## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Docker build context -> image layers | Untrusted local files (secrets, host `node_modules`, `.git`) could leak into the image if not excluded by `.dockerignore` |
| Container runtime -> host kernel | If the process runs as root, a container escape has host-root blast radius instead of an unprivileged user's |
| Any caller -> `GET /health` | Currently unauthenticated by design (Docker `HEALTHCHECK` today, ALB target group in Phase 8) — must never leak infra/credential details in its response |
