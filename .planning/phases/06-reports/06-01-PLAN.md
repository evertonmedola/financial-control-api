## Phase Goal

**As a** signed-in user, **I want to** retrieve a category/period spending summary for any date range I choose, **so that** I can see exactly where my money went without exporting anything or doing the aggregation math myself.

*(ROADMAP.md's Phase 6 `**Goal:**` line — "Users can see clear, aggregated views of their financial activity — by category, across accounts, and over time" — is a plain capability sentence, not authored in strict "As a/I want to/so that" form via `/gsd mvp-phase`. The "so that" clause above is a direct, non-invented restructuring sourced from PROJECT.md's stated core value (real personal use for controlling one's own finances) and REQUIREMENTS.md's REP-01 wording — no new facts added, mirroring 04-01-PLAN.md/05-01-PLAN.md's identical handling of this same situation. If a fuller SPIDR-split user story is wanted, run `/gsd mvp-phase 06` and replant.)*
