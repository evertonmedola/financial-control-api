## Phase Goal

**As a** solo developer publishing a portfolio API, **I want** every push to `main` to be gated by a test suite that is proven to pass from a clean checkout and a repository that is proven safe to make public, **so that** the pipeline built in later plans starts green and nothing sensitive is ever published.

*(ROADMAP's Phase 9 Goal line — "Every push to main is automatically tested, built, and deployed to AWS without manual steps or long-lived AWS credentials" — has no user-story actor; the story above restructures it and Success Criterion 1 without inventing scope, exactly as 07-01 and 08-01 did.)*

## Acceptance Criteria

- [ ] A push to main triggers a pipeline that runs tests (Success Criterion 1, gate half: this plan makes the gate itself green and reproducible before any workflow exists).
- [ ] The repository can be made public without leaking credentials or infrastructure artifacts (D-02).

(This plan lays the free, AWS-free groundwork. Plans 09-02 to 09-05 publish the repo, build the OIDC trust and stack, write the workflow and prove it.)
