Tracer first (Task 1): the thinnest complete path, one push to main runs lint and unit tests, assumes the OIDC role, builds and pushes the SHA-tagged image, renders the live task definition, runs the migration as a separate step, updates the service and ends with the new SHA running on ECS, verified from AWS. Purpose: This is the phase's deploy-half tracer. Every AWS-side assumption (trust subject, PassRole, RunTask scoping, action inputs) is exercised by the first real run; failures are fixed in place (workflow or, for a missing permission, `infra/oidc.tf` plus a human-free `terraform apply`) until the run is green. Because Migrate precedes Deploy and the circuit breaker is armed, a failed run never leaves the service half-updated.
Output: `.github/workflows/deploy.yml`, one successful run per task on `main`, and a recorded failing-migration proof.
</objective>
